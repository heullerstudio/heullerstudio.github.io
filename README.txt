MYEONGDONG 2030 — 팀 공간 소개 사이트 (초안)
=====================================================

1. 여는 방법
-----------------------------------------------------
- zip 파일의 압축을 풉니다.
- 폴더 안의 index.html 을 더블클릭하면 크롬, 엣지, 사파리에서 열립니다.
- 인터넷 연결이 필요 없습니다. 글꼴(Pretendard)도 fonts 폴더 안에 들어 있습니다.
- 파일과 폴더의 위치를 바꾸지 마세요. 폴더 구조가 바뀌면 그림이나 글꼴이 안 보일 수 있습니다.
- 마우스 휠이나 트랙패드로 천천히 내려 보세요. 스크롤을 멈추면 장면도 멈추고, 올리면 거꾸로 재생됩니다.

  ★ 휴대폰(특히 안드로이드)에서 볼 때
  - 휴대폰은 보안 때문에 html 파일 하나만 따로 열고, 옆에 있는 css·js·글꼴 폴더를 읽지 못합니다.
    그래서 index.html 을 휴대폰에서 열면 글자만 파랗게 나오고 디자인이 다 빠집니다. (사이트 고장이 아닙니다)
  - 휴대폰에서는 "MYEONGDONG2030_휴대폰용.html" 하나만 열어 주세요.
    글꼴·그림·코드가 모두 이 파일 안에 들어 있어서 파일 하나만 있어도 똑같이 보입니다.
    카톡이나 드라이브로 이 파일만 보내도 됩니다.
  - 휴대폰용 파일은 "보기 전용"입니다. 문구나 이미지를 고친 뒤에는 폴더 버전(index.html)에서 먼저 확인하고,
    휴대폰용 파일을 다시 만들어 달라고 요청해 주세요.


2. 폴더 구조
-----------------------------------------------------
index.html            메인 페이지 (컴퓨터용)
MYEONGDONG2030_휴대폰용.html   휴대폰에서 볼 때 여는 한 파일 버전
product-01~04.html    제품 개별 페이지 (빈 틀)
css/                  디자인 (색, 글자 크기, 여백)
js/config.js          속도, 길이, 색 설정값
js/content.js         ★ 문구, 제품 이름, 이미지 경로 (주로 여기만 고치면 됩니다)
js/art.js             코드로 그린 그림 (골목 풍경, 릴레이 장면, 사람 실루엣)
js/map.js             하늘에서 본 명동 지도
js/main.js            스크롤 연출
js/page.js            제품 개별 페이지 문구 채우기
fonts/                Pretendard 글꼴 + 라이선스
assets/               이미지 (지금은 파일 이름과 권장 크기가 적힌 빈 칸)
assets/sequence/      영상 프레임을 넣는 폴더 (6번 참고)

따옴표, 쉼표, 괄호는 지우지 마세요. 줄을 바꾸고 싶으면 \n 을 넣으면 됩니다.

  줄 48~51    ⑤ Relay 제목

4. 이미지 바꾸기
-----------------------------------------------------
assets 폴더 안의 파일을 "같은 이름"의 새 파일로 덮어쓰면 끝입니다. 코드는 고치지 않아도 됩니다.
(파일 이름, 확장자 .png 까지 똑같아야 합니다)

  파일                                   쓰이는 곳                      비율 / 권장 크기
  assets/cards/product-01.png ~ 04.png   ⑦ 제품 목록 카드               1:1  / 1200 x 1200
  assets/relay/product-02-use.png ~ 04   ⑤ 릴레이에서 사람이 쓰는 제품   1:1  / 800 x 800 (배경이 투명한 PNG 권장)
  assets/products/product-01-hero.png~04 제품 개별 페이지 대표 이미지   16:9 / 3200 x 1800

  - 카드 이미지는 가이드대로 "단색 배경 위에 제품 단독"이 가장 잘 어울립니다.
    카드 아래쪽에 이름표가 겹치니 제품은 화면 위쪽 2/3 안에 두세요.
  - 릴레이 이미지는 정사각형 칸의 아래쪽에 제품이 바닥에 닿도록 두면 사람 옆에 자연스럽게 서 있습니다.
  - JPG를 쓰고 싶다면 js/content.js 의 경로(.png → .jpg)도 같이 바꿔 주세요.


5. 릴레이 속 제품을 실제 이미지나 3D로 바꾸는 방법
-----------------------------------------------------
(큐브 대신, 사람이 제품을 사용하는 모습으로 만들었습니다)

  ■ 실제 제품 이미지로 : 위 4번처럼 assets/relay/product-0X-use.png 를 덮어쓰기.
  ■ 움직이는 3D로     : 3D 프로그램(Rhino/KeyShot/Blender 등)에서 제품이 돌아가거나 반응하는 짧은 영상을
                        "애니메이션 PNG(APNG)"로 내보내 같은 이름의 .png 로 저장하면 그대로 움직입니다.
  ■ 장면 전체를 영상처럼 : 아래 6번 "영상 프레임 넣기"를 보세요. (가장 화려하게 바꿀 수 있는 방법)
  ■ 사람 실루엣과 PRODUCT 01 장면(노점, FOLD MARK, 접히는 골목 테이블, 음식 컵)은 js/art.js 에 코드로
    그려져 있습니다. 모양을 바꾸고 싶으면 요청해 주세요.


6. 영상 프레임 넣기 (릴레이 장면을 진짜 영상처럼)
-----------------------------------------------------
  애플 제품 사이트처럼, 이미지 여러 장을 스크롤에 맞춰 넘겨서 영상처럼 보이게 하는 방법입니다.
  인터넷 없이도 돌아갑니다.

  ① 3D 렌더나 촬영 영상을 이미지 여러 장(프레임)으로 뽑습니다. (가로 16:9, 1920x1080, JPG 권장, 60~150장)
  ② 파일 이름을 001.jpg, 002.jpg, 003.jpg ... 처럼 세 자리 번호로 맞춥니다.
  ③ assets/sequence/product-01/ 폴더(제품 번호에 맞는 폴더)에 넣습니다.
  ④ js/config.js 의 sequences 부분에서 그 제품의 count: 0 을 장수로 바꿉니다. 예) count: 120
  → 그 제품 차례가 오면 코드로 그린 장면 대신 프레임이 스크롤에 맞춰 넘어갑니다.
     설명 카드, 다음 사람으로 넘어가는 연출은 그대로 유지됩니다.

  ★ 팀원이 직접 연기한 영상으로 "진짜 사람 실루엣"을 만들고 싶다면
     흰 벽 앞에서 옆모습 전신, 휴대폰은 고정한 채로 찍어서 보내 주세요.
     (예: 음식 받기 → 걸어가기 → 테이블 내리기 → 포장 열기) 사람만 검은 실루엣으로 뽑아 프레임으로 만들어 드릴 수 있습니다.


7. 화면 크기 / 접근성
-----------------------------------------------------
- 1920 / 1440 / 1280 화면에서는 같은 비율로 보이고, 390(휴대폰)에서는 연출을 단순하게 바꿔 이야기만 유지합니다.
- 컴퓨터에서 "동작 줄이기(움직임 줄이기)"를 켜 둔 사람에게는 움직임 대신 단순한 페이드로 보여 줍니다.
- 글꼴은 자주 쓰는 한글 2,350자만 담은 가벼운 버전입니다. 아주 드문 글자는 컴퓨터 기본 글꼴로 보일 수 있습니다.
